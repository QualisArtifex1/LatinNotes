# Before you read source material

Copied on 2026-10-12 from https://qualisartifex1.github.io/QualisArtifex/assets/linked-pages/cultural-notes/notes.json and its referenced images/figures files. Text, image captions, and credits are preserved. The renderer follows that site's tables, timelines, paragraphs, and verse quotations.

Commentary adapted from Geoffrey Steadman, College Pliny and Vergil (2023), CC BY-NC-SA 3.0. Individual image credits are in notes.json and displayed with each figure.

This is a bundled copy, not a live feed. To sync later changes, replace notes.json and referenced figures from the source, then run tests/cultural-notes.test.mjs. The app matches the current passage against LATIN_LESSONS, including passages imported through snapshots; custom passages show an unavailable message rather than another lesson's notes.
